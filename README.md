# Window Island

Laman web pendaratan untuk Window Island — aplikasi yang menjadikan Windows 10/11 lebih ringan dan futuristik (top bar, dock, widget hidup, Dynamic Island).

Buka `index.html` terus dalam pelayar, atau hos di GitHub Pages / Netlify / Vercel.

- Kemas kini baharu: tambah entri dalam `CHANGELOG` di `assets/app.js`.
- Harga pakej: ubah atribut `data-m` / `data-y` / `data-l` dalam bahagian `#paket` di `index.html`.
