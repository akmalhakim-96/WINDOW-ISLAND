Soalan Lazim

Adakah Window Island percuma?

Ya. Pakej Free percuma selamanya tanpa had masa. Plus & Pro (bayar sekali) akan datang untuk ciri tambahan.

Versi Windows mana yang disokong?

Windows 10 (versi 1809 ke atas) dan Windows 11, 64-bit.

Windows tunjuk “Windows protected your PC”. Selamat ke?

Ya. SmartScreen memaparkan amaran ini untuk app baharu yang belum ada sijil tandatangan digital berbayar. Klik More info → Run anyway. Kod sumber app ini terbuka di GitHub untuk sesiapa semak.

Antivirus saya tandakan pemasang. Apa perlu buat?

App baharu yang tidak ditandatangani kadang-kadang tersilap dikesan (false positive). Muat turun hanya dari laman ini atau GitHub rasmi. Anda boleh lapor fail tersebut sebagai selamat kepada antivirus anda.

Adakah Window Island hantar data saya ke mana-mana?

Tidak. Tetapan, nota dan peringatan disimpan dalam PC anda sahaja (%AppData%\WindowIsland). App hanya menghubungi internet untuk cuaca (Open-Meteo), carian bandar dan semakan versi baharu.

Adakah taskbar Windows saya akan hilang?

Hanya jika anda hidupkan “Ganti taskbar Windows dengan Dock”. Bila anda keluar atau nyahpasang Window Island, taskbar dipulihkan sepenuhnya.

Adakah notch muncul semasa saya main game?

Tidak. Bila app atau game skrin penuh dibuka, notch dan dock menyorok secara automatik.

Bagaimana nak kemas kini?

Window Island menyemak versi baharu secara automatik dan memaklumkan anda di notch. Muat turun pemasang baharu dan jalankan — tetapan anda dikekalkan.

Ada masalah. Di mana nak lapor?

Buka halaman laporan masalah. Sertakan fail log dari Tetapan → Umum → Buka folder data.
